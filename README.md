# Суши-Муши — электронное меню

Вариант 1 «В стиле кафе»: оформление по фасаду и залу заведения (Учкекен, ул. Ленина, 87).

- вверху — вывеска как на фасаде: круглый логотип ウマロフ и буквы «СУШИ-МУШИ»,
  ниже — белая стена с надписью «То место, о котором все спрашивают»;
- карточка блюда раскрывается «листочком»: состав, штуки, примерные калории и время;
  у сетов — роллы с ценами и выгода «по отдельности / в сете»;
- «Мой заказ»: на панели только число позиций, итог — в окне заказа;
  готовый заказ отправляется в WhatsApp, можно позвонить на любой из двух номеров;
- значок-глазик размывает все цены;
- только для телефона: на компьютере сайт показывается узкой колонкой;
- без сервера: обычные HTML, CSS и JavaScript.

## Как поменять цены и блюда

Всё меню — в одном файле `data/menu.js`. Цена — поле `price`, у вариантов
(3/6/9 шт.) — `price` внутри `variants`. Номер для WhatsApp — поле `whatsapp`.
Фото блюд лежат в `images/dishes/` под тем же именем, что `id` блюда.

Цены и позиции взяты из актуального «меню» в Instagram (сентябрь 2026), недостающие позиции —
из меню, которое присылают в WhatsApp. Калорийность и время — примерная оценка.

## Посмотреть у себя и опубликовать

Посмотреть: дважды щёлкнуть по `index.html`. Опубликовать изменения: запустить `publish.sh`.
